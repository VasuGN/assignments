Mini Library System

A simple library management project built with Python

About My Project

The Mini Library System is a Python project developed to manage books in a library. It allows users to add books, borrow books, return books, and track available copies.

The project uses the Library class and file handling to store book information in JSON formats.

This webpage demonstrates similar library operations using HTML, CSS, and JavaScript.
